# Changelog

## 0.3.0 — source release

- Local dashboard and `csb` PowerShell commands for provider and target selection.
- Windows DPAPI storage for provider keys and persistent launch preferences.
- Responses, Anthropic Messages, and Gemini protocol adapters.
- Catalog, installation, diagnostics, model selection, and restore commands.
- Removed Cursor Agent CLI, Cursor, Windsurf, Kiro CLI, Kiro IDE, and Void targets.
- Added MIT licensing, contribution guidance, security guidance, and dependency notices.

Adapter availability is not a guarantee of compatibility with every provider,
model, or vendor version. See `docs/TARGET_STATUS.md` for recorded verification
and known limitations. This is a source distribution, not a signed Windows installer.
